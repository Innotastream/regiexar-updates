# Xar Tsaroth — Régie du Seuil : mises à jour

Ce dépôt public distribue uniquement les archives applicatives complètes et les manifestes signés de la Régie du Seuil.

- Le code source reste dans le dépôt privé `Innotastream/regiexar`.
- Les fiches, scènes, médias, configurations et secrets ne sont jamais publiés ici.
- Le launcher vérifie la signature Ed25519, la taille et le SHA-256 avant toute installation.
- `main` contient le canal de distribution ; il ne remplace pas la branche stable du dépôt applicatif privé.

Le canal actuellement disponible est `candidate/latest.json`. Une version candidate n’est jamais considérée stable sans validation explicite.
