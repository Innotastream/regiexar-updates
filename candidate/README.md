## Test initial

1. Télécharger et extraire `bootstrap/Xar-Tsaroth-Regie-v1.9.0-ONLINE-BOOTSTRAP-CANDIDATE.zip`.
2. Lancer `start-windows.bat`.
3. Le launcher doit détecter la 1.9.1 publiée dans `latest.json`.
4. Choisir **Installer la mise à jour**.
5. Après relance, la version discrète du launcher doit indiquer `v1.9.1 candidate`.

Le bootstrap et le paquet final ont été construits depuis une source propre, extraits dans des dossiers neufs et retestés. Les données utilisateur restent hors du répertoire programme.
